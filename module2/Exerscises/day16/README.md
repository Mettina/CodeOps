Class Exercise

A JavaScript program that calculates a tip, service fee, total bill, and amount per person.

## Requirements

-> Read the bill amount and party size.
-> Convert the bill using Number().
-> Add 10% tip when the bill is over 300 ETB.
-> Add 5% tip when the bill is 300 ETB or less.
-> Calculate the total.
-> Calculate the amount per person.
-> Use a template literal for the output.
-> Use a switch for the TeleBirr / CBE Birr service fee.
-> Run the program with Node.js.
