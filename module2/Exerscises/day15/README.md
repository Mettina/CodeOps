# Responsive & Animated Habesha Menu

## Class Exercise

This project is a responsive Ethiopian food menu made with HTML and CSS.

## Requirements

* Mobile layout: 1 column
* 768px: 2 columns
* 1024px: 3 columns
* Smooth hover animation
* Use `translateY()` or `scale()`
* Support `prefers-reduced-motion`
* Test from 360px to 1280px
