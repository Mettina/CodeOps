# TeleBirr Transaction Report

A small JavaScript project that processes TeleBirr transactions for an Addis Ababa shop.

## Features

This project demonstrates:

- filter() to select transactions by type
- reduce() to calculate total credits and debits
- map() to create receipt messages
- Destructuring to extract object properties
- ES modules using `import` and `export`

## Files

- transactions.js - Contains the transaction data
- report.js - Contains functions for processing transactions
- app.js - Imports the modules and displays the report

## Technologies

- JavaScript
- ES Modules
- Node.js
