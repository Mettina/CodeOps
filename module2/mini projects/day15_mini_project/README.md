# Habesha Eatery

A responsive static restaurant website for Habesha Eatery in Bole, Addis Ababa.

## Project

This website is built using HTML and CSS only.

## Sections

- Navbar
- Hero
- About
- Menu
- Reservation
- Footer

## Features

- Responsive design
- Mobile-first layout
- Sticky navbar using Flexbox
- Responsive menu cards
- Menu changes from 1 to 2 to 3 columns
- Responsive heading using clamp()
- Reservation form with required fields
- Hover effect on menu cards
- Reduced-motion support
