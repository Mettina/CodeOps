# Birr Budget 

A simple personal budget app for tracking income and expenses using Ethiopian Birr (ETB).

## Features

* Add income and expenses
* View total income
* View total expenses
* View remaining balance
* Calculate saving rate
* Save transactions using LocalStorage
* View recent transactions
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding your transactions.

## Purpose

This project was created as a learning project to practice HTML, CSS, JavaScript, DOM manipulation, forms, and LocalStorage.
