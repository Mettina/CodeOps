# Addis Market Shopping List
# Description

Addis Market is an interactive shopping list application built using HTML, CSS, and JavaScript.

The application allows users to add shopping items with their ETB prices, mark items as bought, delete items, and see a live running total of all item prices.

# Features

- Add a shopping item with a name and ETB price
- Validate that the item name and price are entered
- Add items dynamically using `createElement()` and `append()`
- Mark an item as bought by clicking its row
- Delete items using event delegation
- Display a live running total of ETB prices
- Prevent the form from reloading the page
- Use CSS to style the bought state

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- DOM Events
- Event Delegation
