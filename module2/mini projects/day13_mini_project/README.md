# Kazanchis Pharmacy Business Card

This project is a one-page business profile card for Kazanchis Pharmacy in Addis Ababa.

-> CSS variables defined in ":root"
-> "var()"used throughout the stylesheet
-> Global "box-sizing" ,"border-box"
-> Google Fonts (Inter)
-> Centered card layout
-> Padding, borders, margins, and border radius
-> Typography hierarchy
-> :hover and :focus states
->::before pseudo-element
-> Responsive images
