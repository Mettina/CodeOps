# Addis Eats day1

A static Ethiopian restaurant menu built with React and Vite.

## Features

- Reusable Header component
- Reusable Dish component
- Props for dish name and price
- Menu stored in an array
- Menu rendered using map()
- Unique keys using dish IDs
- Prices displayed in ETB

## Technologies

- React
- JavaScript
- Vite
- CSS
