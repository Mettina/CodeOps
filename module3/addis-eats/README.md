# Addis Eats Menu App

A fast, lightweight dynamic restaurant menu build with React and Vite. This application utilizes modular component structures, prop-drilling with object destructuring, and dynamic array rendering using JavaScript loop maps.

## Getting Started

Follow these instructions to run the application locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed on your computer.

### Installation & Run Steps
1. Clone or download this project folder.
2. Open your terminal inside the project directory and install the necessary package modules:
   ```bash
   npm install
   ```
3. Boot up the local Vite development server instance:
   ```bash
   npm run dev
   ```
4. Open your web browser and navigate to the local hosting URL:
   `http://localhost:5173/`
