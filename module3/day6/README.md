## ✨ Features

### Core Features
- ✅ **Nested Routing** with Layout components
- ✅ **Dynamic Routes** for dish details (`/menu/:id`)
- ✅ **Protected Routes** for checkout page
- ✅ **Query String Filtering** for category selection
- ✅ **404 Not Found** page for invalid routes
- ✅ **Active Navigation** with NavLink highlighting

### User Experience
- ✅ Persistent login state with localStorage
- ✅ Automatic redirect after login
- ✅ Category filter persists in URL
- ✅ Responsive design for all devices
- ✅ Clean and modern UI

## 🛠️ Tech Stack

- **React 18** - UI Library
- **React Router DOM v6** - Routing
- **Vite** - Build Tool
- **CSS3** - Styling
- **LocalStorage** - Session Management

### Prerequisites
