# Module 3 — Addis Eats

Each subfolder is a **separate, standalone Vite + React project** for one day.
They build on each other conceptually (same app, growing in complexity),
but each folder runs independently — `cd` into whichever day you're on,
then install and run.

| Folder | Focus | Run |
|---|---|---|
| `day1/` | Setup, JSX, components, props | `cd day1 && npm install && npm run dev` |
| `day2/` | PropTypes, conditional rendering, `children`, filtering with early return | `cd day2 && npm install && npm run dev` |
| `day3/` | State, lifting state up, controlled forms, live validation | `cd day3 && npm install && npm run dev` |
| `day4/` | `useEffect`, fetching data, loading/error states, `AbortController`, `useRef` | `cd day4 && npm install && npm run dev` |

Each day's exercises are just the steps that build that day's mini-project —
they aren't separate tasks. Read the `README.md` inside each folder for what
changed and why.
