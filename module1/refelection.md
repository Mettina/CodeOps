# Reflection

1. What is the difference between Git and GitHub?
- Git is a version control tool that runs on my own computer and tracks changes to my files.
- GitHub is a website that hosts Git repositories online, so I can back up my work and share it with others.

2. What is the purpose of the terminal?
The terminal lets me control my computer by typing commands instead of clicking through menus.
It's faster, more precise, and required for tools like Git.

3. What does git add do?
It stages changes — moving edited files from the working directory into the staging area,
marking them as ready to be included in the next commit.

4. What is the purpose of git commit?
It saves a permanent snapshot of everything currently staged, along with a message
describing what changed.

5. Daily Git workflow in order:
   1. git pull
   2. Do the day's work
   3. git add .
   4. git commit -m "message"
   5. git push
